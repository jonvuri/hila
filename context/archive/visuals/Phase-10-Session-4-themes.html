Phase 10 · Session 4 — Visual direction fan-out

Three theme catalogs, built to the same skeleton (inspiration → foundations → chrome → components → gestalt → dials) with the same demo content (the "Reading queue" scenario), so they compare cell-for-cell. Each is a standalone page with a dark/light toggle and live dials — open them full-size and play with the knobs.

Intent (per the session brief): a creative fan-out first; at least two survivors later, to force the token/theming system to span genuinely different languages — the same way the substrate face forces discipline on view configuration.

Side-by-side: where the themes actually disagree

These axes are the future token system's stress tests — any two survivors must both be expressible by the same semantic tokens.

AxisWipeoutNullUltramodern
Accent discipline Focus / selection / live only. A lit element means something is happening. Conventional. Interactive, selected, linked — what users expect. Expressive. Selection, primary action, live — with glow; accent behaves like light.
Corners 0 radius; one chamfer per filled block (canon-compatible). 5/8px radius — the invisible default (canon break, dial to 0 available). 12/18px + pills (full canon break).
Bounds Suggested: header + rule + 3-corner brackets; full enclosure only for modals. Hairline cards; enclosure is normal and expected. Material panes; the edge is a lit surface boundary, not a line.
Depth Hard edge-steps + brightness (ancestor staircase). No shadows ever. Shadows for true overlays only; resting UI is flat on paper. Literal altitude: blur, translucency, layered shadows everywhere.
Type voices Three strict voices: display (structure) / mono (instrumentation) / body (content-as-guest). One family; weight and gray do all the work. One family, tight tracking, heavy weights; one gradient flourish per composition.
Texture VFD ghost segments (alpha only — no blur/gradients). None. Texture is the absence of texture. Frosted glass, ambient washes, fresnel "impossible objects".
Launcher Fully-bracketed instrument over a flat scrim; key-legend footer. Standard centered modal with real shadow; quietest possible chips. The centerpiece: heaviest glass, icon tiles, gradient selection, blurred scrim.
Ancestry Edge-step staircase with monogram stubs. Breadcrumb text line. Receding pill crumbs.
Overlaid cards (§5b) Tab layer = descending strip of chamfered bars (baselines staircase 3px/depth); edges step brightness instead of fading; active tab = accent marker. Plus a dedicated deep dive with 6 concepts (gauge, edge-on sheets, spines, chevrons, terrace). Tab layer = per-column breadcrumb runs, each flush over its column; ancestor cards = hairline slivers; titles redundantly in crumb and panel (deliberate Resolution-B break). Cards = literal glass panes at altitudes; ancestors visible through the pane in front; tab layer = column-locked pill groups, active = gradient pill.
Danger Semantic red only when armed; hold-to-confirm segment strip. Hover-revealed red (platform convention). Hover-revealed red wash.
Main risk Uppercase/mono pressure in an all-day text tool. Total collapse into the mundane if the quirk budget goes to zero. Blur cost + marketing-skin-on-a-workshop dissonance.

How to review

  • Each catalog: toggle dark/light (top-right) — both polarities are meant to be first-class in all three.
  • Play the dials (§6): Wipeout's accent hue + display face + chamfer; Null's quirk budget + radius + label register; Ultramodern's blur + glow + radius + gradient stop.
  • Judge the gestalt (§5) before the parts — the same shell mock exists in all three.
  • The §4c launcher and §4d table are the highest-stakes comparisons: they carry the 3b chip grammar and the ƒ formula mark in every theme.
  • §5b stream is where each theme gets stretched: the 7b overlaid-cards mechanics (tab layer, ancestor edge cards, depth staircase) morphed per theme, plus the full three-panel Miller stream (root nav · combined focus/nav · active focus) on identical content. In Null and Ultramodern the ancestry runs are column-locked — each column's path segments sit flush above it.
  • The Wipeout × Overlaid Cards deep dive explores six concepts for physically representing deep hierarchy in Miller columns (instrument strip, depth gauge, edge-on sheets, spines, chevron flow, terrace) with a side-by-side judgment table.
