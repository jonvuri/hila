Phase 10 · Session 4 · Visual direction fan-out

NullTHEME 02 / 03

Academic and professional. Every choice is the expected one — system-grade type, hairline borders, quiet hovers, a small radius — so the interface disappears and comprehension is instant. Distinctiveness survives only as one or two controlled quirks imported from Wipeout (currently: the square-flag label and the margin tick), which are dials, not defaults.

01  unsurprising to the point of invisible 02  as few elements as focus requires — no fewer, no more 03  accent used conventionally: interactive, selected, linked 04  quirks are budgeted: two, max, and they must never obstruct

N3

Chrome · panel anatomy & depth

A panel is a card: surface, hairline, radius. Focus = a slightly stronger border plus the margin tick (if the quirk is on) — deliberately near-invisible, because in this theme content order, not chrome, carries focus. Ancestry is a breadcrumb line, the most conventional answer available. Depth: in-flow surfaces never cast shadows; only true overlays (menus, launcher) do.

N5b

Stream · overlaid cards & Miller columns

The 7b mechanics survive intact — ancestor edge cards, per-depth steps — but the tab layer reads through the most conventional lens available: a plain breadcrumb, split into per-column runs. Each column's ancestry segments sit flush above that column, so the crumb row doubles as the column map — you always know which path segment a column answers for. Segments are quietly clickable (hover reveals a dotted underline); the current column's own name is the bold terminal segment, with the accent dot marking the active panel. Null still breaks 7b's Resolution B on purpose: titles appear in both crumb and panel — redundancy in favor of instant comprehension.
