Create a clean, precise desktop software UI wireframe comparing two variants of a heterogeneous records table in a personal notes app. This is a product design exploration, restrained grayscale with very subtle blue type badges, white background, legible typography, no device frame, no decorative art. Clearly distinguish types with small Film / Note / Card badges and subtle separators while preserving original order, never regroup the last film with the first two. Notes and cards have no secondary fields, no fake empty film cells. Include small down-chevron per row implying collapse detail fields.
