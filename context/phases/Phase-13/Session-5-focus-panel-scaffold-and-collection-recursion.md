# Phase 13 Session 5 — Focus-panel scaffold and collection recursion

## Goal

Complete the focus panel as a host-owned identity, fields, collection, and relations scaffold. Make
subject mode, affinity, recursion, and fidelity determine interiors without giving faces shell
ownership.

## Depends on

Sessions 1–4 must provide recipe resolution, design inputs, the registered table collection, and
host-consumable property lines.

## Requirements

- Keep panel identity, intrinsic fields, overflow fields, collection region, relations, insertion
  policy, breadcrumbs, sizing, and navigation in the host.
- Resolve loose, container, and view subjects through one host path. Missing renderings use the
  substrate floor without creating a recipe.
- Let nested subjects return to host slots rather than allowing one face to mount another face.
- Apply composed/substrate fidelity locally and inherit it recursively. Active x-ray must force the
  entire descendant host tree to substrate.
- Preserve view SQL on the marker subject, recognized source-cell write-back, and the prohibition on
  structural insertion, drag, or inferred ownership from query results.
- Replace the panel's remaining legacy and inline visual roles as part of the complete local surface
  boundary.

## Boundaries

- Do not change rooted navigation, panel retention, saved-view identity, query semantics, or URL
  behavior.
- Do not add a general region-layout plugin API.
- Do not store fidelity in recipes or persist x-ray.
- Do not redesign source/sticky row continuity before Session 7.

## Acceptance

- Every focus panel region has one clear host or face owner.
- Loose aspects, dedicated tables, saved views, intrinsic fields, and relations preserve their
  current behavior through one scaffold.
- Nested rendering terminates through host slots and the substrate fallback without face-owned
  recursion.
- Composed, substrate, and x-ray behavior is correct across mixed nested subject modes.
- Focus-panel styles consume canonical roles without leaving a parallel legacy boundary.

## Verification

- Run focused focus-panel, view-place, query-band, substrate-region, embedded-table, relations, and
  face-runtime suites.
- Exercise mixed loose/container/view nesting, absent renderings, invalid views, write-back, and
  insertion-firewall cases.
- Inspect themes, polarities, fidelities, narrow presentation, and accessibility in Storybook and
  the system browser.
- Run formatter, linter, static types, the full unit suite, focused E2E, and `git diff --check`.

## Handoff

Session 6 applies the same runtime contract to the workspace's row and expanded-block hosts.
