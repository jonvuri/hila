# Phase 13 Session 9 — Legacy-style retirement and closeout

## Goal

Remove the remaining compatibility runtime and legacy presentation residue, prove the complete
Phase 13 boundary, and hand a coherent host runtime to Phase 14.

## Depends on

Sessions 1–8 must be complete. Every live surface needs its focused behavioral and visual evidence
before this removal pass begins.

## Requirements

- Audit all live style consumers and remove obsolete global palette aliases, dead surface rules,
  bypasses, compatibility registrations, and superseded rendering paths.
- Keep only genuine global reset, root, and application-wide token responsibilities in global
  styles. Surface behavior belongs to its maintained local boundary.
- Confirm no direct face mount, face-owned recursion, automatic unused table recipe, manual
  workspace recipe lookup, or temporary adapter remains.
- Verify the whole application across themes, polarities, composed/substrate fidelity, x-ray,
  responsive shell presentation, component variants, reduced motion, and representative data
  states.
- Recheck accessibility, virtualization, sticky scrolling, editor residency, launcher behavior,
  rooted navigation, and performance after the removals.
- Promote shipped contracts into canonical topics, record schema and durability truth, close every
  session, and route the next action to Phase 14.

## Boundaries

- Do not begin Phase 14 task/review faces during closeout.
- Do not remove worker-free retired-surface references that still serve as historical visual
  evidence.
- Do not describe a planned contract as shipped before its full verification passes.
- Do not activate durable schema version 1; the dogfooding gate remains event-based.

## Acceptance

- No executable compatibility face runtime or legacy live-surface style boundary remains.
- The one-recipe/implicit-substrate model, registered interiors, host recursion, scaffold, affinity,
  and fidelity work coherently across all production subjects.
- Embedded tables, inline tags, property editing, rooted navigation, launcher behavior, responsive
  panels, sticky continuity, and system-edge administration retain their supported behavior.
- The full application is readable, operable, and semantically consistent across the complete
  design-axis matrix.
- Canonical documentation, the roadmap, Phase 13, and `NOW.md` agree on the shipped and deferred
  boundaries.

## Verification

- Run formatter, linter, static types, and the full unit suite.
- Build Storybook and inspect the approved live and historical references.
- Run focused system-browser suites for every migrated surface, then the full E2E suite with the
  system-installed browser.
- Run performance guards and the throttled browser backstop where affected contracts require it.
- Run schema-policy and two-replica verification if Phase 13 changed schema or replicated state.
- Run `git diff --check`, verify active documentation links, and inspect the final deletion list.

## Handoff

After all gates pass, mark Phase 13 complete, record its shipped boundary in the front door, and
route `NOW.md` to the rewritten Phase 14 structured-aspects plan.
