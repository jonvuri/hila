# Hila

Hioa 3.0

Unified feedback matrix

## How to run

`npm start`

Runs the app in the development mode.<br>
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

Set `VITE_HILA_VISUAL_THEME` to `ghost`, `null`, or `wipeout` before startup to select the visual
theme. Missing or invalid values use Ghost.

```sh
VITE_HILA_VISUAL_THEME=wipeout npm start
```

## How to build

`npm run build`

Builds the app for production to the `dist` folder.<br>
